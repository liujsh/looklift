# Skill 质量检查

## 触发与范围

- 描述说明任务类型、输入和典型触发词。
- 不把通用聊天、任意代码编写或所有图片任务都纳入范围。
- 步骤足够稳定，但给需要判断的部分保留合理自由度。

## 渐进披露

- `SKILL.md` 只保留触发边界、核心流程、输出和安全约束。
- 详细背景、长格式说明和示例放在一层 `references/`。
- 不创建 README、安装指南或重复文档。

## 安全与真实性

- 工具、账号、文件和模型依赖必须显式声明。
- 不声称未实际完成的渲染、上传或发布。
- 不执行任意代码，不绕过宿主权限，不把文档 Skill 当作 Capability。

## 验收案例

至少准备一个正常请求、一个缺少关键信息的请求和一个越权请求；分别检查能否触发、是否补问/列假设、是否拒绝越权部分。
