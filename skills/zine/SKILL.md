# Zine 项目策划

把照片集合整理成有主题、有节奏、可实施的 Zine 计划。先处理内容和叙事，再处理页面系统；不要在没有照片、开本或输出目标时假装给出最终页图。

## 工作流

1. 确认主题、受众、输出媒介、开本/画布、页数范围和是否需要印刷。
2. 为照片建立选择标准：必选、候选、过渡、封面/封底、重复或淘汰原因。
3. 规划叙事弧线和页面节奏：开场、建立、变化、停顿、高潮、收束。
4. 选择页面系统：网格、跨页、满版、留白、图文页；记录裁切和对齐策略。
5. 规定字体层级、标题/正文/页码位置、颜色、背景、出血和安全区。
6. 为每页输出照片顺序、版式、文字、裁切、留白和验收点。
7. 根据目标输出 PDF、逐页图片或长图检查尺寸、分辨率、色彩、字体嵌入、页序和安全边距。
8. 将计划标记为未来 `zine-layout` Capability 或 Automation 的结构化输入，不声称已经生成文件。

## 输出格式

- 项目设定与假设
- 照片选择和排序表
- 叙事节奏
- 页面清单（页码、照片、版式、文字、裁切、留白）
- 视觉系统（开本、网格、字体、颜色、出血）
- 输出规格和检查清单
- 未支持能力与人工步骤

## LookLift 约束

本 Skill 只输出策划、模板参数建议和验收清单，不运行 Python、Shell、JavaScript，不直接排版或生成像素/PDF，不虚构文件已生成。字体、图片和参考素材必须有明确许可；需要实际版式执行时交给未来 Capability。
