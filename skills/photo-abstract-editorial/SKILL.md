# 抽象摄影编辑

把抽象或 editorial 风格需求转成可讨论、可预览、可学习的编辑计划，而不是直接生成像素结果。先区分照片内容问题、系列叙事问题和风格表达问题，再决定哪些能由 LookLift 当前白盒参数近似完成。

## 工作流

1. 说明项目意图、受众、输出媒介和希望保留的真实感。
2. 观察或询问主体、几何形状、负空间、重复、遮挡、运动和色彩关系；不要凭空补写未看到的内容。
3. 将问题分为构图/选择、明暗、色彩、层次、节奏和文字/版式六类。
4. 先制定低风险调整顺序：曝光与白平衡 → 明暗层次 → 色彩关系 → 风格强度 → 输出规格。
5. 对每一步写出目标、可用的白盒参数方向、预期副作用和预览检查点。
6. 标出当前能力不能可靠完成的局部蒙版、生成式擦除、内容重构或复杂排版，并给出人工或未来 Capability 方案。
7. 输出“诊断 → 编辑计划 → 参数建议 → 预览评审 → 系列一致性检查”。

## 输出格式

- 项目意图与假设
- 照片/系列诊断
- 编辑优先级
- 每步的白盒参数方向与风险
- 预览前后需要比较的事实
- LookLift 能力限制与人工步骤
- 系列一致性验收清单

## LookLift 约束

只建议当前参数契约允许的全局调色方向；不得生成代码、直接修改像素、虚构已经完成渲染或把抽象风格词机械映射成大幅滑杆变化。需要局部蒙版、内容生成或复杂版式时，明确标记为未支持能力。
