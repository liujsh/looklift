# v2.4 需求：模板与教学

## 目标

把已有内置模板和用户风格提升为平台级模板资产：用户能浏览、理解、直接套用，也能把模板作为
AI 对话附件，让 AI 依据当前照片做自适应调整。所有路径仍只修改同一份白盒 `analysis`。

## 用户故事

| 编号 | 用户故事 | 本期交付 |
|---|---|---|
| U16 | 希望有开箱即用的经典风格 | 展示 LookLift 原创的青橙、胶片、日系官方模板 |
| U27 | 上传照片后从大师模板起手再微调 | 从模板页或 Studio 直接套用，进入同一版本历史 |
| U33 | 想理解模板原理或交给 AI 自适应 | 展示适用场景、关键参数与步骤；聊天框可附加模板 |

## 验收标准

- [ ] “大师模板”页列出官方模板与用户模板，来源、只读属性和空状态明确。
- [ ] 官方模板卡片包含原创风格说明、适用场景、关键参数和分步教学。
- [ ] 用户模板使用其已有摘要、步骤和白盒参数生成教学视图，不修改用户文件格式。
- [ ] 有已打开 Studio 时可直接套用模板；无 Studio 时给出明确引导，不静默失败。
- [ ] 模板套用复用现有编辑 Store、渲染和会话版本，不建立独立效果层。
- [ ] AI 输入框可以选择一个模板附件；发送时把模板名称和白盒参数意图加入本轮请求，
  不上传模板文件，不绕过既有安全代理图与 provider 边界。
- [ ] 官方模板继续只读；用户模板继续通过现有收藏链路写入。

## 非目标

- 社区模板市场、上传、点赞、排行和作者主页。
- 复刻知名摄影师、VSCO 或其他商业预设的具体参数。
- 以 LUT、参考图或生成式模型形成不可解释的黑盒模板。
- 为模板维护第二套参数范围、默认值或版本历史。
- 在缺少作者确认的代表照片时伪造模板效果前后图；首版以色彩语义和参数教学呈现卡片。
