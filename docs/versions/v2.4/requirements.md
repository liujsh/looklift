# v2.4 需求：模板与教学

## 目标

把已有内置模板和用户风格提升为平台级模板资产：用户能浏览、理解、直接套用，也能把模板作为
AI 对话附件，让 AI 依据当前照片做自适应调整。所有路径仍只修改同一份白盒 `analysis`。

## 用户故事

| 编号 | 用户故事 | 本期交付 |
|---|---|---|
| U16 | 希望有开箱即用的经典风格 | 展示 LookLift 原创的青橙、胶片、日系官方模板 |
| U27 | 上传照片后从大师模板起手再微调 | 从模板页或 Studio 直接套用，进入同一版本历史 |
| U33 | 想理解模板原理或交给 AI 自适应 | 展示适用场景、关键参数与步骤；聊天框可附加模板 |

## 验收标准

- [ ] “大师模板”采用两级页面：目录页只负责浏览与选择，点击卡片进入独立详情页；不在目录页
  同时常驻教学详情，避免挑选与学习信息争夺空间。
- [ ] 来源（官方模板/我的模板）与分类（全部/人像/自然/电影/黑白/夜景/旅行）是两个独立
  筛选维度；分类下直接展示具体模板，不增加第三层导航。
- [ ] 支持按名称、摘要、分类和适用场景搜索；用户模板缺少分类时进入“未分类”，且仅在确有
  此类模板时显示该分类入口。
- [ ] 模板卡片只保留预览、名称、分类和简短摘要，不放教学、参数表或套用按钮；套用按钮仅位于
  独立详情页。
- [ ] 官方模板详情页包含原创风格说明、适用场景、完整参数和分步教学。
- [ ] 用户模板使用其已有摘要、步骤和白盒参数生成教学视图，不修改用户文件格式。
- [ ] 卡片预览采用 4:3、固定 50/50 的原片/效果对比；详情页提供大型可拖动、可键盘操作的
  Before/After。卡片没有合法预览时回退白盒参数指纹，不伪装成照片效果。
- [ ] 详情页从完整 look `analysis` 展示基础、曲线、逐色 HSL（色相/饱和度/明亮度）、颜色分级
  和效果参数；目录 API 的关键参数摘要不替代完整参数视图。
- [ ] 参数不用抽象数据表呈现：基础与效果使用契约驱动的只读滑杆，曲线绘制真实形状，HSL 使用
  三维度页签与八色滑杆，颜色分级使用色轮；默认只看有调整的参数，并可切换显示全部。
- [ ] 未打开照片时仅可使用明确授权的官方示例图；打开照片后，右栏默认用当前照片生成临时
  预览。临时预览不提交参数，切换模板或照片时过期请求不能覆盖新结果。
- [ ] 有已打开 Studio 时可直接套用模板；无 Studio 时给出明确引导，不静默失败。
- [ ] 模板套用复用现有编辑 Store、渲染和会话版本，不建立独立效果层。
- [ ] AI 输入框可以选择一个模板附件；发送时把模板名称和白盒参数意图加入本轮请求，
  不上传模板文件，不绕过既有安全代理图与 provider 边界。
- [ ] 官方模板继续只读；用户模板继续通过现有收藏链路写入。

## 非目标

- 社区模板市场、上传、点赞、排行和作者主页。
- 复刻知名摄影师、VSCO 或其他商业预设的具体参数。
- 以 LUT、参考图或生成式模型形成不可解释的黑盒模板。
- 为模板维护第二套参数范围、默认值或版本历史。
- 使用原型占位图、第三方预设网站截图、宣传图、水印资产或未知版权照片作为模板预览。
- 把为验证 30 个模板布局而生成的虚拟结构项写入最终产品数据。
