1. 先用离线测试固定模板卡片投影与 API 契约，再实现官方教学元数据和用户模板降级。
2. 扩展模板目录的一级分类投影；实现来源、分类、搜索和选择逻辑。
3. 按最终原型实现暗房浏览区与暖纸教学栏，复用现有 `LookliftClient`、Studio runtime 和正式
   版本提交链路；当前照片预览只走可取消的临时渲染，不提交版本。

   参数对象分组展示，不新增参数真相源。

6. 补前端特征测试、回填架构与开发日志，并对成型代码 diff 自审一次。
