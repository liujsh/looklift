# v2.4 设计：模板与教学

## 边界

`lookstore` 继续拥有模板参数文件；新增模板目录投影只组合已有 `analysis` 与官方教学元数据，
不改变分析 schema。后端提供面向卡片的只读模板目录；前端负责浏览、教学展开和操作编排。

## 数据契约

模板卡片包含：名称、来源、只读标记、摘要、适用场景、教学步骤和关键参数路径。关键参数值
仍从对应 look 的 `analysis` 读取；官方教学元数据只描述“为什么”和适用场景，不复制参数值。
目录投影另包含一级分类；官方分类来自随包教学元数据，用户模板不迁移原文件且默认投影为
“未分类”。用户模板没有官方元数据时，从已有 `summary`、`steps` 和非中性参数生成安全降级视图。

## 交互

1. 平台“大师模板”目录页以来源、一级分类和搜索正交筛选；卡片只显示识别所需的预览、名称、
   分类和摘要。点击卡片进入该模板的独立详情页，返回时保留目录筛选与搜索状态。
2. 卡片预览位固定为 4:3；有明确授权的同分类示例资产时使用同一原片的固定 50/50 引擎输出，
   否则回退参数指纹。详情页大图允许拖动和键盘调整分割位置。
3. 详情页读取选中 look 的完整 `analysis`，按基础、曲线、HSL、颜色分级和效果分组展示；HSL
   对每个颜色通道同时展示色相、饱和度和明亮度。参数值来自同一对象，不复制范围或默认值。
   数值范围和中性点由现有 `ParamContract` 驱动滑杆；曲线、色轮和 HSL 颜色轨道只读展示，真正
   编辑仍在 Studio 调整面板完成。默认过滤中性项，“显示全部”只改变可见性，不改变参数。
4. 最近 Studio 存在时，详情页默认加载当前照片的临时 Before/After；先读取选中 look 的完整
   `analysis`，再复用 `/api/preview` 生成 factor 0/1 两侧。请求可取消，结果只更新预览 URL，
   不写 Store、不生成版本。无当前照片且无授权示例时继续显示参数指纹。
5. “直接套用”只位于详情页；它寻找最近使用且仍存活的 Studio，读取模板 analysis，经 Store 正式提交并由
   SessionCoordinator 持久化，然后激活该 Studio；没有 Studio 时显示“请先打开照片”。
6. Studio 聊天框的 `＋` 打开模板选择器。选中项以可移除附件 chip 展示；发送时把模板名称、
   摘要和“基于模板自适应当前照片”的约束写入文本请求。附件本身不改变当前正式版本。
7. Studio 原有底部模板带继续保留，直接套用语义与模板页一致。

## API

- `GET /api/templates`：返回模板卡片目录；损坏 look 继续沿用现有跳过策略。
- `GET /api/looks/<name>`：继续作为完整白盒参数读取入口，不新增重复详情接口。

## 安全与兼容

- 官方教学元数据随包只读，官方模板仍不能覆盖。
- 用户 look JSON 形状不变，旧图库无需迁移。
- 分类集合是目录展示契约，不成为新的参数真相源；原型布局占位数据不进入 API 或随包数据。
- 示例图必须有可追溯授权；原型几何图与第三方站点资产不得进入产品。参数指纹明确标注为参数
  示意，不得表达或暗示照片效果。
- 模板附件只扩展当前用户消息，不改变 provider、图片代理、元数据开关和两轮精修规则。
- 所有名称继续通过既有 look 路由校验，前端不拼接文件路径。
