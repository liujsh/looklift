# v2.3-B 设备导入需求

## 目标

在本地图库已有索引能力之上，提供相机、存储卡和手机目录的离线导入入口。用户可以发现设备、浏览照片、按日期和重复状态筛选，选择文件复制到图库并在完成后进入 Studio。

## 契约

- RAW 与 JPEG 是两个独立项目；不根据文件名强制配对。
- 重复项按内容 SHA-256 指纹判断，默认不勾选，用户可显式选择。
- 导入先写入目标目录同目录临时文件，尺寸与 SHA-256 校验通过后原子改名；失败任务保留可清理的临时文件，不触碰设备原片。
- 目标目录没有图库索引时自动加入根目录并扫描；已有索引只刷新扫描。
- 导入任务支持进度轮询和协作式取消。取消不删除设备文件，已完成文件保持可用。
- 首个成功导入文件可作为 Studio 会话入口；本版本 API 返回全部成功路径供 UI 决定会话策略。
- 不做云同步、设备写入、删除/移动设备原片和黑盒像素处理。

## 验收

离线测试覆盖设备发现、日期/重复筛选、原子复制校验、重复跳过、取消与图库刷新；前端覆盖导入页选择和任务状态展示。
